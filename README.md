# basenefit · 運動成長空間

棒球訓練的學員／教練工作台。單一 HTML 檔、不用安裝任何東西，手機自動變單欄。

## 頁面

| 頁面 | 內容 |
|------|------|
| 運動首頁 | 本週節奏、本週數據、今日動作清單 |
| 動作影片 | 上傳動作影片（MP4/MOV/WebM，25MB 內）、影片庫、**教練回饋留言** |
| 能力評估 | 左右腳平衡、30 秒椅子坐站、傳球命中＋教練觀察，可多次記錄 |
| 訓練計畫 | 今日動作清單（逐項打勾）、**課表月曆**、每週節奏、教練建議 |
| 進步追蹤 | 累積次數／時間、本週長條圖、能力前後比較、訓練紀錄 |
| 教練工作區 | 學員總覽（負責教練、訓練紀錄、評估、影片）、訓練安排、待觀察影片 |
| 學員與設定 | 切換目前教練（Aaron / William / Stanley）、新增教練、雲端同步、匯出資料 |

## 資料保存

- 預設存在**使用者自己的瀏覽器**（localStorage），不會上傳到任何地方。
- 要讓多人共用同一份資料 → 依 `deploy/README-雲端同步.md` 接上自己的 Google 試算表。

## 開發／修改

- 全部在 `index.html` 一個檔案裡（HTML + CSS + JS，無建置流程）。改完直接重新整理即可。
- 品牌名、標語、教練名單都在 `index.html` 內可搜尋到（例如 `base<b>benefit</b>`、`TRAIN · TRACK · GROW`、`coaches: [...]`）。

## 授權與注意

- 版面結構參考自使用者提供的示範網站；**品牌文案請使用自己的內容**，不要直接複製他人的行銷文字。
- 影片目前只記錄檔名與中繼資料，**不會真的儲存影片檔**；AI 動作分析尚未接上。
