# basenefit — 雲端同步設定（Google 試算表當資料庫）

做完這 6 步，學員／教練在不同手機上就會看到同一份資料。**不用付任何費用。**

## 步驟

1. 打開 https://sheets.new （**用 tsaitepiao@gmail.com 登入**）→ 建立一份新試算表，命名例如 `basenefit 資料`。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把左側 `Code.gs` 的內容全部刪掉，貼上這個資料夾裡的 **`Code.gs`** 全文，按 💾 儲存。
4. 右上角 **部署 → 新增部署作業** → 齒輪選 **網頁應用程式**：
   - 說明：`basenefit api`
   - **執行身分：我（tsaitepiao@gmail.com）**
   - **具有應用程式存取權的使用者：任何人**
   - 按 **部署** → 第一次會要求授權：選「進階」→「前往（不安全）」→ 允許
     （會出現「不安全」是因為這是你自己寫的未驗證腳本，只有你自己的帳號會用到，正常）
5. 複製產生的 **網頁應用程式網址**（結尾是 `/exec`）。
6. 回到 basenefit 網站 → **學員與設定 → 雲端同步** → 貼上網址 → 按「儲存網址」。
   - 之後按 **上傳到雲端**（把本機資料寫進試算表）或 **從雲端下載**（把手機／電腦的資料拉回來）。

## 注意

- 網址**每次重新部署都會變**，換了新網址記得重貼一次。
- 資料存在你自己的 Google 試算表的 `basefit-state` 工作表裡（第 2 列一列 JSON）。
- 想備份：直接在試算表「檔案 → 下載」即可；想還原就把那格 JSON 複製回網站（或改用自己的 Apps Script）。
- 目前設計是「整份資料覆蓋」：**上傳前建議先按一次「從雲端下載」**，避免兩台裝置互相蓋掉。之後要做「多人同時編輯自動合併」需要更完整的後端（屆時可改用 Firebase 或 Supabase）。
